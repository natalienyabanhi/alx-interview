ALX Interview Preparation

This repository contains a collection of technical interview challenges solved during the ALX Software Engineering Specialization. 

The goal is to master data structures, algorithms, and problem-solving techniques commonly tested in technical interviews.
For every challenge in this repository, I follow a rigorous process:

   1. Analyze: Understand the constraints and edge cases.
   2. Strategy: Choose the most efficient data structure (Hash Maps, Trees, Stacks, etc.).
   3. Optimize: Aim for the best time and space complexity (Big O).
   4. Dry Run: Test the logic with sample inputs before final implementation. [5, 6]
